# 目录地图

本仓库是学习容器。草稿在 `practices/`，稳定代码在 `src/tinytorch/`，断言在 `tests/`。

## 顶层

| 顶层路径 | 用途 |
| --- | --- |
| `src/tinytorch/` | 可安装包（导入名 `tinytorch`）。子包：`tensor`、`autograd`、`nn`、`optim`、`data`、`training`、`export`。 |
| `practices/` | 七个阶段的草稿目录；稳定代码再迁入 `src/`。 |
| `tests/` | 与阶段对应的测试。除骨架冒烟外留空。 |
| `scripts/` | `run_training.py`、`export_checkpoint.py` 入口占位。 |
| `docs/` | 目录地图、练习顺序、运行、调试、导出（简体中文）。 |
| `pyproject.toml` | 发行名 `tinytorch-learn`，版本 `0.1.0`，可选 `dev`（pytest）。 |

## 写代码的位置

| 顺序 | 草稿 | 库实现 | 测试 |
| --- | --- | --- | --- |
| 01 张量 | `practices/01_tensor/` | `src/tinytorch/tensor/` | `tests/test_tensor.py` |
| 02 自动求导 | `practices/02_autograd/` | `src/tinytorch/autograd/` | `tests/test_autograd.py` |
| 03 神经网络 | `practices/03_nn/` | `src/tinytorch/nn/` | `tests/test_nn.py` |
| 04 优化器 | `practices/04_optim/` | `src/tinytorch/optim/` | `tests/test_optim.py` |
| 05 数据管道 | `practices/05_data/` | `src/tinytorch/data/` | `tests/test_data.py` |
| 06 训练循环 | `practices/06_training/` | `src/tinytorch/training/` | `tests/test_training.py` + `scripts/run_training.py` |
| 07 导出 | `practices/07_export/` | `src/tinytorch/export/` | `tests/test_export.py` + `scripts/export_checkpoint.py` |

## 包布局

```
src/tinytorch/
  __init__.py          # 仅 __version__
  tensor/__init__.py
  autograd/__init__.py
  nn/__init__.py
  optim/__init__.py
  data/__init__.py
  training/__init__.py
  export/__init__.py
```

每个子包目前只有模块说明，没有类或函数实现。迁入时保持这个导入路径，方便其他项目 `import tinytorch`。

## 练习目录

每个 `practices/0N_*/` 含：

- `README.md`：本阶段目标与迁入位置
- `practice.py`：空草稿
- `.gitkeep`：保证空目录可被 git 跟踪

不要在练习目录里复制官方 TinyTorch。写完一阶段并通过测试后，把稳定接口搬进对应的 `src/tinytorch/<子包>/`。
