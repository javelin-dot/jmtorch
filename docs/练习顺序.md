# 练习顺序

后一阶段只依赖已经迁入 `src/tinytorch/` 的接口。不要跳过迁入：草稿可以很乱，库路径要稳定。

## 推荐顺序

1. **张量**（`practices/01_tensor/` → `src/tinytorch/tensor/`）
   存储、形状、切片、广播、基础运算。先能表示数据，再谈求导。
2. **自动求导**（`practices/02_autograd/` → `src/tinytorch/autograd/`）
   计算图、`backward`、梯度累积。张量运算要能留下可反传的痕迹。
3. **神经网络**（`practices/03_nn/` → `src/tinytorch/nn/`）
   `Module`、线性层、激活、损失，接到 autograd。第一层就应该能反传。
4. **优化器**（`practices/04_optim/` → `src/tinytorch/optim/`）
   `step` / `zero_grad`，至少实现 SGD。
5. **数据**（`practices/05_data/` → `src/tinytorch/data/`）
   `Dataset` / `DataLoader`。玩具数据即可，重点是按 batch 取出。
6. **训练循环**（`practices/06_training/` → `src/tinytorch/training/`）
   取 batch → 前向 → 损失 → 反传 → 更新。损失应能下降。入口占位：`scripts/run_training.py`。
7. **导出**（`practices/07_export/` → `src/tinytorch/export/`）
   权重保存与加载；固定对外导入路径。入口占位：`scripts/export_checkpoint.py`。

## 与官方 TinyTorch 的差异

官方 TinyTorch 常把激活 / 层 / 损失拆开，并放在 autograd 之前。这里**先求导再接线层**，便于第一层就能反传。

本骨架没有卷积、注意力、量化等后续课。需要时再加 `practices/08_*`，不要塞进现有阶段把接口搅乱。

## 完成一阶段的标志

- 草稿里的行为已经收敛
- 稳定接口已迁入 `src/tinytorch/<子包>/`
- 对应 `tests/test_<阶段>.py` 有真实断言
- 下一阶段只 `import tinytorch...`，不再依赖 `practices/` 里的临时名字
