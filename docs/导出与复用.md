# 导出与复用

这个包给其他项目用时，只安装仓库本身，不要拷贝 `practices/` 或测试进去。

## 给其他项目安装

在对方虚拟环境里：

```bash
pip install -e /path/to/tinytorch-learn
```

然后只 `import tinytorch` 及其子包。不要 `sys.path.append` 到本仓库的 `practices/`。

版本写在两处，必须一致：

- `pyproject.toml` 的 `version`
- `src/tinytorch/__init__.py` 的 `__version__`

当前都是 `0.1.0`。改版本时两处一起改。

## 建议的公开表面（实现之后）

| 能力 | 建议导入 |
| --- | --- |
| 张量 | `tinytorch.Tensor` 或 `tinytorch.tensor.Tensor` |
| 反传 | `backward` |
| 模块 / 线性层 / 损失 | `tinytorch.nn.Module`、`Linear`、损失类 |
| 优化器 | `tinytorch.optim.SGD` |
| 数据 | `tinytorch.data.Dataset`、`DataLoader` |
| 训练 | `tinytorch.training.fit` |
| 权重 | `tinytorch.export.save`、`tinytorch.export.load` |

这些名字现在还不存在。实现第 7 阶段时再冻结它们。一旦其他项目开始 `import`，就不要随意改路径。

## 导出检查点

`src/tinytorch/export/` 负责保存与加载权重。`scripts/export_checkpoint.py` 是命令行入口占位，实现后应调用 `export.save` / `export.load`，而不是自己另写一套格式。

建议：

- 保存的是层权重，不是整个 Python 进程
- 加载后能继续 `forward`（训练循环接上后，损失曲线应能接着走）
- 文件格式由你定，但导入路径保持 `tinytorch.export`

## 不要导出的东西

- `practices/` 草稿
- 测试夹具
- `.venv`
- 官方 TinyTorch 或 PyTorch 的任何源码
