# 运行指南

需要 Python 3.10+。所有命令都在仓库根目录执行。

## 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

uv 也可以：

```bash
uv venv
source .venv/bin/activate
uv pip install -e ".[dev]"
```

`pip install -e .` 会按 `pyproject.toml` 把 `src/tinytorch` 装成可编辑包，导入名是 `tinytorch`，发行名是 `tinytorch-learn`。

## 测试

```bash
pytest
```

或 `uv run pytest`。

当前只应收集并通过对 `tests/test_package.py` 的冒烟：能 `import tinytorch`，且 `tinytorch.__version__ == "0.1.0"`。版本号必须与 `pyproject.toml` 里的 `version` 一致。

各阶段文件（`tests/test_tensor.py` 等）是占位，没有断言，pytest 不会当失败。实现某阶段后，把断言写进对应文件，再单独跑：

```bash
pytest tests/test_tensor.py
pytest tests/test_autograd.py
```

## 脚本

| 脚本 | 将来做什么 | 现在 |
| --- | --- | --- |
| `scripts/run_training.py` | 调用训练循环 | 只有说明，没有训练 |
| `scripts/export_checkpoint.py` | 写出或读入权重 | 只有说明，没有写文件 |

实现第 6、7 阶段后再把这两个入口接上。在此之前运行它们应直接退出或打印“尚未实现”，不要假装训练成功。

## 导入检查

```bash
python -c "import tinytorch; print(tinytorch.__version__)"
```

应打印 `0.1.0`。子包现在也可以导入（`tinytorch.tensor` 等），但里面没有可用的类或函数。
