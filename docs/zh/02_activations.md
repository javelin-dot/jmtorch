## 💡 入门：神经网络为什么需要激活函数？

先比较两种情况：

**不使用激活函数，只做线性或仿射变换**：
```
输入 → 第一次变换 → 第二次变换 → 输出
 x   → 2x + 1     → 3(2x + 1) + 4 = 6x + 7
```
无论叠多少次，这类变换仍能合并成一次。这里用有明确定义的标量例子替代未给出权重的向量箭头，以便逐步验算。

**在变换之间加入非线性激活**：
```
输入 → 第一次变换 → ReLU 激活 → 第二次变换 → 输出
 x   → 2x + 1     → max(0, 2x + 1) → 3·max(0, 2x + 1) + 4
```
例如 `x=-1` 时输出为 4，`x=0` 时输出为 7。这个函数在 `x=-0.5` 两侧有不同斜率，无法在全部输入上合并为同一条直线。

激活函数引入**非线性**，使模型可以弯折函数形状、组合复杂的决策边界。“决策边界”就是模型将不同类别分开的分界线或分界面。

### 非线性为何重要？

没有激活时，多个仿射变换的组合仍是仿射变换：
```
A₂(A₁x + b₁) + b₂ = (A₂A₁)x + (A₂b₁ + b₂)
```
这表示可以找到一组等效的新权重与偏置，不是说前后两层的参数相同。

加入非线性后，不同阶段可以组合越来越复杂的模式，例如：
```
第 1 阶段：简单边缘与线条
第 2 阶段：曲线与形状
第 3 阶段：复杂物体与概念
```
这是图像网络中常见的解释性示意，具体学到什么仍取决于结构和训练。非线性让简单数学运算组成更强的函数近似器。

## 📐 数学基础

不同激活函数在计算中有不同用途。

### 五种核心激活函数

1. **Sigmoid**：数学上把有限实数映射到 `(0, 1)`，常用于二分类概率或门控。
2. **ReLU**：把负数置零，产生包含许多零值的稀疏激活；计算本身很简单。
3. **Tanh**：数学上映射到 `(-1, 1)`，输出以零为中心；这是一种有用性质，但不保证训练一定更好。
4. **GELU**：具有类似 ReLU 的平滑门控行为，常见于 Transformer 等结构。
5. **Softmax**：沿指定轴把一组分数归一化为概率分布，各分量互相依赖。

“逐元素”表示一个输出只取决于对应位置的输入，前四种属于这一类；Softmax 则要比较同一轴上的所有分数。浮点运算有舍入：Sigmoid/Tanh 的极端值可以等于数学开区间的端点，Softmax 的极小概率也可能变成零。

## 🏗️ 实现：构建激活函数

### 统一的实现方式

每个激活函数采用相似结构：
```python
class ActivationName:
    def forward(self, x: Tensor) -> Tensor:
        # 对输入应用数学变换。
        # 用新的 Tensor 返回计算结果。
```

`forward` 表示前向计算，也就是由输入求输出；`__call__` 让 `activation(x)` 等价于调用相应的前向方法。`parameters()` 返回空列表，因为这些激活没有可训练参数。没有参数不等于无需梯度：训练时仍要把梯度传回输入，计算图与反向传播在第 06 模块接入。

### Sigmoid——把分数压缩到概率范围

Sigmoid 在数学上把任意有限实数映射到 `(0, 1)`，适合表达二分类概率和门控强度。把一个数放进概率范围，并不自动保证它是校准准确的概率，仍需要合适的数据与训练目标。

#### 数学定义
```
σ(x) = 1 / (1 + e^(-x))
```
`e` 是自然常数，约为 2.718；`exp(x)` 就是 `e^x`。当输入增大时，输出逐渐靠近 1；当输入减小时，输出逐渐靠近 0。

#### 输入输出示例
```
输入：[-3,   -1,    0,    1,    3]
        ↓     ↓     ↓     ↓     ↓  Sigmoid 变换
输出：[0.05, 0.27, 0.50, 0.73, 0.95]（近似值）
```

#### 文本曲线示意
```
Sigmoid 曲线：
    1.0 ┤          ╭───────
        │        ╱
        │      ╱
    0.5 ┤─────●──────────
        │    ╱
        │  ╱
    0.0 ┤╱────────────────
       -3      0       3
```

**为什么有用**：二分类常需要一个介于 0 和 1 的输出，例如“属于正类”的预测概率。Sigmoid 的零点输出为 0.5，表示两侧对称。

**数值稳定小提示**：直接算 `exp(-x)` 在很大的负输入处可能溢出。本实现对正负输入分别使用等价公式，选择指数不大于零的结果；`np.where` 会先求值两个分支，`np.errstate` 负责忽略被丢弃分支的中间溢出警告。浮点输出在极端输入处可能舍入为 0 或 1。

**梯度直觉**：导数是 `σ(x)(1-σ(x))`；两端接近平坦，称为饱和区，多层传播时可能造成很小的梯度。

**测试内容**：普通输入的输出位于 `(0, 1)`，并验证零点与极端输入。  
**意义**：确认输出适合表示概率式数值，并检查稳定计算。  
**预期结果**：`sigmoid(0)=0.5`；普通测试值严格位于两端之间；极端值有限且接近 0 或 1。

### ReLU——产生稀疏激活

ReLU（修正线性单元，Rectified Linear Unit）是常用的隐藏层激活。它把负值置零，保留非负值，从而产生含许多零的输出；这种现象叫作**稀疏性（sparsity）**。

#### 数学定义
```
f(x) = max(0, x)
```

#### 输入输出示例
```
输入：[-2, -1, 0, 1, 2]
        ↓   ↓  ↓  ↓  ↓  ReLU 变换
输出：[ 0,  0, 0, 1, 2]
```

#### 文本曲线示意
```
ReLU 函数：
 y
 2 │       ╱
 1 │     ╱
 0 ├────●──────── x
      -2 0  1  2
负半轴输出为零，正半轴斜率为 1。
```

**为什么有用**：ReLU 的比较运算简单，并在正区间保留信号。稀疏激活可能影响表征与泛化，但并不保证避免过拟合。当前 Tensor 使用 NumPy 稠密数组，零仍占空间，后续稠密运算也不会自动跳过零；只有合适的稀疏存储与计算实现才可能利用这种结构加速。

**梯度直觉**：负区间导数为 0，正区间导数为 1；零点在数学上不可导，本项目后续反向实现采用零点导数为 0 的约定。

下面验证 ReLU 的前向行为。

**测试内容**：负值变零，正值保留，并统计产生的零。  
**意义**：核对截断规则与稀疏激活，为后续网络组合提供可靠组件。  
**预期结果**：负数输出 0，正数保持原值，输入 0 仍输出 0。

例如 `[-1,-2,-3,1]` 应得到 `[0,0,0,1]`，共有 3 个零。这里验证数值性质，没有测量稀疏硬件加速。

### Tanh——以零为中心的选择

Tanh（双曲正切，hyperbolic tangent）与 Sigmoid 一样呈 S 形，但中心在零，数学输出范围为 `(-1, 1)`。正负输出能围绕零分布，是组合多次变换时常用的性质。

#### 数学定义
```
f(x) = (e^x - e^(-x)) / (e^x + e^(-x))
```

#### 输入输出示例
```
输入：[-2,    0,   2]
        ↓     ↓    ↓  Tanh 变换
输出：[-0.96, 0, 0.96]（近似值）
```

#### 文本曲线示意
```
Tanh 曲线：
    1 ┤     ╭─────
      │    ╱
    0 ┤───╱─────
      │  ╱
   -1 ┤─╱───────
     -3  0  3
```

**为什么有用**：Sigmoid 的输出非负，而 Tanh 允许正负输出且满足 `tanh(-x)=-tanh(x)`，即关于原点对称。零中心不保证所有训练任务都更好；Tanh 两端也会饱和，其导数 `1-tanh(x)²` 会趋近零。

实现使用 `np.tanh`，而非直接计算上面的多个指数。float32 在大幅值处可舍入为 -1 或 1，因此测试允许闭区间端点。

下面验证 Tanh 的输出范围、零点和对称性。

**测试内容**：数学范围为 `(-1, 1)`，数值测试考虑浮点端点；函数以零为中心。  
**意义**：检查组合变换时依赖的数学性质。  
**预期结果**：输出位于 `[-1, 1]`，`tanh(0)=0`，并满足 `tanh(-x)=-tanh(x)`；极端输入接近 ±1。

### GELU——平滑的现代激活选择

GELU（高斯误差线性单元，Gaussian Error Linear Unit）具有类似 ReLU 的门控行为，在 Transformer 等架构中很常见。ReLU 在零点有折角；GELU 是平滑函数，但它并不等于把 ReLU 的折角简单磨圆，负半轴还会出现小负值。

#### 数学定义

精确 GELU 把 `x` 乘以 `Φ(x)`。`Φ(x)` 是标准正态随机变量小于等于 `x` 的概率，也叫标准正态分布的累积分布函数，形状是从 0 到 1 的 S 形曲线：
```
GELU(x) = x · Φ(x)
```

常见的两种近似形式（Hendrycks 与 Gimpel，2016）：
```
Tanh 近似：   0.5x(1 + tanh[√(2/π)(x + 0.044715x³)])
Sigmoid 近似：x · σ(1.702x)                            ← 本地采用
```
Tanh 形式通常对精确 GELU 的近似更准确；速度取决于底层算子、硬件和实现，不能断言 Sigmoid 形式总是更快。本章选择 Sigmoid 形式以复用刚实现的类，常数 1.702 由拟合得到，使 `σ(1.702x)≈Φ(x)`。

#### 输入输出示例
```
输入：[-1,       0,      1]
        ↓        ↓       ↓  本地 GELU 近似
输出：[-0.1542,  0,  0.8458]（近似值）
```
精确 GELU 在 ±1 处约为 -0.1587 和 0.8413；不要把这两组近似混为一谈。

#### 文本曲线示意
```
GELU 函数（示意）：
 y
 1 │                     ╱
   │                   ╱
 0 ├───╮───────────●─╱──── x
   │    ╰────────╯
       -2    -1    0    1
负半轴有小幅下凹；经过零点时平滑，没有 ReLU 的尖角。
```

**为什么有用**：BERT、早期 GPT 等模型使用 GELU 或其近似，平滑门控会改变优化时的梯度行为，但并不保证比 ReLU 更好。模型家族与版本也可能采用其他激活。

**后续求导提示**：这里使用 `x·σ(1.702x)`，令 `s=σ(1.702x)`，导数应为 `s+1.702x·s(1-s)`，不能套用另一种近似的导数。

### Softmax——把一组分数变成概率分布

Softmax 沿指定轴把有限分数归一化为概率分布，常用于互斥的多分类输出。数学上每项为正且总和为 1；浮点下总和应按容差判断，极小项可能下溢为零。输入含 NaN 或无穷大时，本实现不保证有效概率。

#### 数学定义
```
f(x_i) = e^(x_i) / Σ_j e^(x_j)
```
`Σ` 表示求和；分母对同一归一化轴上的全部类别求和。因此一个类别的概率会受其他类别分数影响。

#### 输入输出示例
```
输入：[1,     2,     3]
       ↓      ↓      ↓  Softmax 变换
输出：[0.090, 0.245, 0.665]  ← 近似总和为 1
```

#### 文本变换示意
```
Softmax 变换：
原始分数：[1, 2, 3, 4]
             ↓ 计算指数
          [2.7, 7.4, 20.1, 54.6]（四舍五入）
             ↓ 用总和归一化
          [0.03, 0.09, 0.24, 0.64]  ← 总和约为 1
```

**为什么有用**：多分类需要为各类别分配概率，Softmax 提供这种归一化形式。它不能单独保证预测准确或概率校准。

**形状小例子**：输入形状为 `(2,3)`，把 `dim=-1` 传给 `forward` 或调用运算后，每行的三个类别概率之和为 1。`keepdims=True` 让行最大值与行总和保持 `(2,1)`，便于广播回 `(2,3)`。本类不接受构造参数 `Softmax(dim=...)`，要写 `Softmax()(x, dim=...)`。

**稳定性推导**：同时减去常数 `c` 时，分子分母都有因子 `e^(-c)`，相除后抵消。取每行最大值为 `c`，指数的输入便不大于零，可避免大正数的指数溢出；这仍不能避免所有小概率下溢。

#### 🧪 单元测试：Softmax

下面验证 Softmax 的归一化、排序与形状行为。

**测试内容**：普通分数形成有效的概率分布，大分数计算保持有限，二维输入按最后一轴归一化。  
**意义**：多分类输出需要正确选择类别轴，不能把不同样本混在一起求和。  
**预期结果**：本测试普通输入的输出严格在 `(0,1)`，最大输入对应最大概率，各行总和在容差内等于 1，形状保持不变。

`[1000,1001,1002]` 与 `[0,1,2]` 只相差公共常数，Softmax 应相同；减最大值可避免直接求大指数导致的溢出。

### 理解各激活函数的输出模式

结合前面的函数与测试，可以看到每种激活各有用途：

**Sigmoid**：数学上压缩到 `(0,1)`，常用于概率或门控。  
**ReLU**：负值置零、正值保留，产生稀疏激活。  
**Tanh**：类似 Sigmoid 的 S 形变换，但范围为 `(-1,1)`，以零为中心，便于某些变换组合。  
**GELU**：平滑的 ReLU 式门控，现代网络结构中的常见选择。  
**Softmax**：把同一轴上的分数组成概率分布，总和在数值容差内为 1。

不同计算任务需要不同输出性质。一个实用区别是：多个独立标签常各用一个 Sigmoid；多个互斥类别才常用一组 Softmax。数学开区间要与浮点舍入边界区别理解。

## 🤔 机器学习系统思考题

通过下面的问题，深入理解激活函数及其对系统设计的影响。

### 1. 计算成本比较

**问题**：ReLU 是常见的隐藏层激活。结合你的实现，为什么它的基本计算通常比 Sigmoid 或 GELU 简单？

**思考方向**：
- ReLU 需要什么数学操作？提示：`max(0,x)`。
- Sigmoid 需要什么操作？提示：指数、加法和除法。
- 隐藏层含 100 万个元素时，每种实现调用了多少次 `np.exp`，每次又处理多少个元素？本地稳定 Sigmoid 在 `np.where` 两侧共出现三次 `np.exp` 表达式，而且两个分支都会求值；不要把 Python 调用次数和逐元素计算次数混为一谈。

**实际背景**：大型模型中，小的逐元素成本会累积。但“ReLU 快 3～4 倍”不是通用常数，应结合本机基准、数组大小、内存流量和实现判断。

---

### 2. 数值稳定性

**问题**：Softmax 为什么先减去最大值再计算指数？

**思考方向**：
- `exp(1000)` 在常用浮点类型中会怎样？
- `exp(1000)/(exp(1000)+exp(1001))` 为什么可能变成 `inf/inf`，进而得到 NaN？
- 给全部输入减同一个常数，会改变最终 Softmax 吗？

**数学提示**：
`exp(x_i-c)/Σ_j exp(x_j-c) = exp(x_i)/Σ_j exp(x_j)`，因为公共因子 `exp(-c)` 抵消。试着把 `[1000,1001]` 改写成 `[-1,0]` 后再计算。减最大值避免大正指数溢出，但不能保证所有小概率都不下溢。

---

### 3. 稀疏性与效率

**问题**：ReLU 把负值变零。如果大量激活为零，何时可能有利于计算？

**思考方向**：
- 内存：零与非零一定采用不同存储吗？本项目的 NumPy 稠密数组中并没有区别。
- 运算：乘以零的结果是什么？实际计算内核是否会跳过这次乘法？
- 学习：对某个输入有一半单元“关闭”，表征中仍保留了哪些信息？

**进一步考虑**：
- 稀疏矩阵格式如何节省数值存储，又会引入多少索引开销？
- GPU 怎样处理稀疏运算，对结构和稀疏比例有什么要求？
- 哪些计算受益，哪些可能因不规则访问而更慢？

---

### 4. 为不同阶段选择激活函数

**问题**：为什么隐藏阶段与输出阶段常使用不同的激活？

**比较需求**：
- 隐藏阶段：需要传递有用信息、控制成本并加入非线性。
- 二分类输出：需要表示一个事件的概率，数学范围为 `(0,1)`。
- 多分类输出：互斥类别需要总和为 1 的概率分布。

**把函数与用途对应起来，并解释原因**：
- 隐藏阶段用 ReLU。
- 二分类输出用 Sigmoid。
- 互斥多分类输出用 Softmax。

**与下一章衔接**：训练时若损失函数直接接收 logits（尚未归一化的分数），可能不应先手动做激活；本地 `CrossEntropyLoss` 接收 logits，避免重复 Softmax。

---

### 5. “死亡 ReLU”问题

**问题**：ReLU 对负输入输出零，负区间梯度也为零。什么情况会让某个单元长期无用，为什么这是问题？

**思考方向**：
- 某个单元在相关训练样本上的输入始终为负时，输出持续为零。
- 一次输出零不等于永久“死亡”；持续的负区间输入与零梯度才会妨碍该单元恢复。
- 死亡单元仍占参数内存和计算，却难以贡献有效信号，相当于浪费模型容量。

**实践中的缓解方法**：
- LeakyReLU：`f(x)=max(0.01x,x)`，允许负区间保留小斜率。
- PReLU：用可学习参数调整负区间斜率。
- GELU：平滑门控，负区间通常保留小信号；但 `GELU(0)=0`，极端负输入在浮点下也可能得到零，不能说“永不归零”。

---

### 加分挑战：内存分析

**场景**：推理时，一个隐藏层输出形状为 `(batch=32, features=4096)`，尝试不同激活。

**分别计算或检查**：
1. 若每个输出是 float32，需要多少字节？提示：`32×4096×4=524288` 字节，即 512 KiB。
2. Softmax 相比 ReLU 产生了哪些临时数组？沿最后一轴时，最大值与总和数组形状是 `(32,1)`，平移值与指数值形状是 `(32,4096)`；实际峰值还与中间对象生存期有关。
3. 如果系统真正把存储从 float32 改为 float16，理论数据字节数减少多少？答案是减半；但当前 Tensor 默认转换到 float32，仅给输入换 dtype 不代表整个框架已支持 float16。

**关键认识**：本章激活输出形状与输入相同，参数量为零，但仍需要输出及临时内存。速度、数值精度和峰值内存都应结合实际实现评估。
